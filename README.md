# navi Browser 🌐
A lightweight, minimal web browser built with Python and PyQt5 and PyQt6.

## 📥 Download
**👉 [Download version 1 here, use the command prompt below for the lastest version](https://github.com/omxrprob/navi-browser/releases/latest)**  
After downloading, just run the `OmxrBrowser.exe` file.

> ⚠️ Windows might show a warning — click **More info → Run anyway**.

[join our discord server for more information](https://discord.gg/2ps9Fq6fpH)

## 🛠️ How to Build
### before i tell you how to download it, make sure you have Git and python installed in your computer.
first do this in the terminal(microsoft shell tab):
```bash
git clone https://github.com/overthrowncats/navi-browser.git
```
then hit enter, then do this:
```bash
cd navi browser
```
after that, click enter again and do this:
```
pip install -r requirements.txt
```
hit enter again, after that is the last step, do this:
```
python simple_browser.py
```
